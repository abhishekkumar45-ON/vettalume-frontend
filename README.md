# VettaLume Test Frontend

React and Next.js implementation of the VettaLume homepage from the provided Figma file.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Included

- Next.js App Router setup
- TypeScript configuration
- Responsive VettaLume homepage
- Local brand SVG assets
- ESLint setup
